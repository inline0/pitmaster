# Unit Tests

Oracle scenarios prove git compatibility. Unit tests prove internal algorithm correctness where oracle comparison is not meaningful: encoding edge cases, error handling, algorithm invariants, and malformed input rejection.

## Running tests

```bash
# All unit tests
composer test:unit

# Or directly with PHPUnit
./vendor/bin/phpunit

# Specific test suite
./vendor/bin/phpunit --testsuite unit
./vendor/bin/phpunit --testsuite integration

# Specific test file
./vendor/bin/phpunit tests/Unit/Encoding/Leb128Test.php

# Specific test method
./vendor/bin/phpunit --filter testDecodeMaxValue tests/Unit/Encoding/Leb128Test.php
```

## Test suites

```
  Diff/
    MyersDiffTest.php        # Empty inputs, single-line, identical files

  Merge/

    CommitWalkerTest.php     # Topological ordering on synthetic graphs
```

## Key test patterns

### Encoding round-trips

```php
// Every encoded value must decode to the original
$original = 12345;
$encoded = VarInt::encode($original);
$decoded = VarInt::decode($encoded, $offset);
$this->assertSame($original, $decoded);
```

### Malformed input rejection

```php
// Corrupt data must throw typed exceptions, never return wrong data
$this->expectException(PackParseException::class);
$pack = new PackFile($truncatedPackPath);
$pack->readEntry(0);
```

### Algorithm invariants

```php
// Myers diff: applying the diff to the old content must produce the new content
$hunks = MyersDiff::diff($old, $new);
$applied = applyHunks($old, $hunks);
$this->assertSame($new, $applied);
```

### Boundary conditions

```php
// Empty inputs
$hunks = MyersDiff::diff('', '');
$this->assertSame([], $hunks);

// Identical inputs
$hunks = MyersDiff::diff($content, $content);
$this->assertSame([], $hunks);

// Single character
$hunks = MyersDiff::diff('a', 'b');
$this->assertCount(1, $hunks);
```

## Static analysis

PHPStan level 5:

```bash
composer analyse
# Or directly:
./vendor/bin/phpstan analyse
```

Configuration in `phpstan.neon.dist`:

```neon
parameters:
    level: 5
    paths:
        - src
```

## Coding standards

PSR-12 via PHP_CodeSniffer:

```bash
# Check
composer cs

# Fix automatically
composer cs:fix
```

Configuration in `phpcs.xml`:

```xml
<ruleset name="Pitmaster">
    <rule ref="PSR12"/>
    <file>src</file>
    <file>tests</file>
</ruleset>
```

## PHPUnit configuration

From `phpunit.xml.dist`:

```xml
<phpunit>
    <testsuites>
        <testsuite name="unit">
            <directory>tests/Unit</directory>
```

## CI integration

The test suite runs in CI with:

1. `composer install`
2. `composer cs` (coding standards check)
3. `composer analyse` (static analysis)
4. `composer test:unit` (unit tests)
5. `./bin/test-regression --fast` (oracle scenarios, pass/fail)

The oracle scenarios require the `git` binary to be installed in CI. Unit tests do not.
